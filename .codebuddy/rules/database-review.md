# Database Review Rules

进行数据库设计时优先从业务规则推导，不先从 CRUD 反推表。

重点检查：
- 实体是否遗漏或重复
- 一对一 / 一对多 / 多对多关系
- 业务关系是否需要独立实体
- 主键与外键
- 唯一约束
- NOT NULL 与默认值
- 时间字段
- 状态字段
- 索引
- 数据一致性
- Service 与数据库约束的职责边界

重点业务：
- 同一球场时间冲突
- 同一用户重叠时间最多两个预约
- 同一用户不能重复报名
- 同一用户不能重复点赞

不要直接生成 SQL，除非开发者已经确认表结构方案。
