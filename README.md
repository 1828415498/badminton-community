# Badminton Community

> 羽毛球社区后端项目（AI 辅助开发）

## 项目简介

Badminton Community 是一个面向大学生及校外羽毛球爱好者的社区平台，第一版围绕“找球、约球、场地预约、社区交流”建立核心业务闭环。

## 当前项目阶段

当前处于：**项目立项与需求设计阶段**。

尚未进入业务代码开发。

## 核心业务（V1）

- 用户注册、登录、个人资料
- 羽毛球活动创建、审核、发布、取消、结束
- 场地预约与取消
- 活动报名与取消报名
- 社区帖子、评论、点赞
- 管理员审核与基础管理

## 技术路线

项目计划采用 Java + Spring Boot 单体架构，并在业务需要时逐步引入 Redis、并发控制、MQ、Docker、Linux/Nginx 等技术。

## AI 开发方式

AI 作为开发助手参与需求分析、设计 Review、编码、测试、Debug、重构和文档维护；核心业务规则、架构决策和最终验收由开发者负责。
