这张图修了什么

原图有 5 处字段与 sql/schema.sql 对不上。逐条列出：

#原来画的问题现在
1 post.status 表里没有这一列（post 只有 id / user_id / title / content / create_time / update_time） 已删除
2 post.like_count 表里没有这一列。点赞数是"能算出来的量"，属导出项，落在视图 v_post_with_stats 里实时 COUNT 已删除，卡片内注明原因
3 reservation.cancel_source 表里没有这一列，只有 cancel_time 已删除
4 user 卡片漏字段 漏了 avatar_url —— 头像上传功能靠它 已补上
5 user → venue 虚线「管理 / 创建」 没有任何列支撑：venue 表里没有 created_by 之类的字段 已删除（不画没有列支撑的连线）
一条铁律：这张图上的每一条连线，都必须由表里一个真实存在的外键列支撑。
反过来说 —— 图里没有画出的外键关系，一律在对应卡片的注释行里写明（例如 post_like 的两列同时是外键）。
